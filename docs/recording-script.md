# Screen-recording run sheet (about 6 minutes)

Use the live app at `http://localhost:5173` (or the preview link). Record the screen and narrate in your own voice. Keep the app in full-screen/windowed browser view, scroll deliberately, and pause long enough for each result to be readable. The script is a guide—replace the bracketed tool name with the tool(s) you actually used.

## 0:00–0:25 · Login

**On screen:** TalentLens sign-in. Click **Continue in demo mode**.

**Say:** “This is TalentLens, a prototype for a recruiter-led hiring workflow. I used **[name the AI tool you actually used]** to help plan or build the prototype. For transparency, the demo’s file extraction and scoring run locally with a deterministic heuristic; it is not connected to a live LLM, and no CV text is sent to a model or server.”

## 0:25–1:10 · Upload the JD

**On screen:** Click **Use fictional sample JD**, then **Analyze brief**. Point to role, skills, experience and location.

**Say:** “I’m loading the fictional AI/LLM Engineer job description. TalentLens extracts the role, the core technical signals, the three-to-five-year experience range and Bengaluru location. I can edit the result before moving on. The location is shown for context, not used in candidate scoring.”

## 1:10–1:45 · Upload five fictional CVs

**On screen:** Continue to **Upload CVs** and click **Load 5 fictional sample CVs**. Show the count and the 3 PDF / 2 Word split.

**Say:** “I’m using five synthetic resumes only—three PDFs and two Word files. The app extracts selectable text in this browser and confirms how many it could read. These candidates are fictional and contain no real contact information.”

## 1:45–2:50 · Stack ranking and human correction

**On screen:** Click **Rank candidates**. Show the score, reason, matched and missing skills. Point to the rubric, then click **Exclude unsupported match** in the review flag.

**Say:** “Each candidate is scored on the same evidence rubric: required skills, stated experience, delivery evidence and role alignment. Names and protected traits are not used, and the scores are not a hiring decision. I’m checking a likely false positive: Candidate 04 mentions LangChain only in a tutorials note and explicitly says there was no hands-on use. I exclude that unsupported match; the matched and missing skills update and the score changes from **[read the on-screen score]** to **[read the updated score]**. A recruiter should review every result.”

## 2:50–3:45 · Screening questions

**On screen:** Continue to **Screening questions**. Scroll through all ten prompts and their “good answer” guidance.

**Say:** “Here are ten phone-screen questions grouped across technical depth, experience and role fit. Each has a guide to what a strong answer might include, so the recruiter can ask consistent follow-ups rather than rely on a score alone.”

## 3:45–4:55 · Hiring-market insights

**On screen:** Continue to **Market insights**. Show company, experience, compensation, location and at least one source link. Point out estimate labels.

**Say:** “This market panel uses public hiring signals from company careers and job-board pages, plus a broad Bengaluru compensation guide. Where an employer did not publish pay, the amount is clearly marked as an estimate rather than company-confirmed compensation. Listings can expire, so I’d verify the source before using the numbers. I did not log in to or scrape LinkedIn or Naukri.”

## 4:55–5:45 · Search strings

**On screen:** Continue to **Search strings**. Show both Boolean and plain versions for Naukri and LinkedIn; optionally click a copy button.

**Say:** “Finally, TalentLens turns the same brief into Boolean and plain-language search strings for both Naukri and LinkedIn. These are suggestions to run manually through each site’s normal interface; the prototype does not automate searches or contact candidates.”

## 5:45–6:05 · Close

**On screen:** Keep the search strings visible.

**Say:** “That completes the seven-step workflow. The important guardrail is that the tool supports a recruiter’s review—it does not make the hiring decision. All test CVs in this walkthrough are fictional.”

**Timing:** about 6:05 at a measured pace. The brief’s stated deadline was 11 October 2026, 4:00 PM IST; that date has passed as of 18 October 2026. If submitting late, check with the assessor about whether a late link is still accepted.
